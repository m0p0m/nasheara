
## اطلاعات ورود به پنل مدیریت

> نام‌کاربری و رمز عبور به‌صورت پیش‌فرض از `.env` خوانده نمی‌شوند. در اولین ورود، این داده‌ها را از فرم ورود وارد کنید و سیستم آن را در جدول `AdminUser` دیتابیس ذخیره می‌کند. از آن‌پس، اعتبارسنجی فقط از دیتابیس انجام می‌شود.

برای ورود به پنل مدیریت، به آدرس `/admin/login` یا `/login` بروید.

## نصب و راه‌اندازی

1. نصب وابستگی‌ها:
```bash
npm install
```

2. ایجاد فایل `.env` (از `.env.example` کپی کنید):
```env
PORT=3001
SESSION_SECRET=your-secret-key-here-change-in-production
ADMIN_USERNAME=admin
ADMIN_PASSWORD=$2b$10$I2x6Hp6vLXESIuk6v98Y1.fmiHLRIsii7qbQQND5S3Rbw2Qof580K
```

3. اجرای سرور:
```bash
npm run dev
```

سرور روی `http://localhost:3001` اجرا می‌شود.

## ساختار پروژه

- `controllers/` - کنترلرهای برنامه
- `models/` - مدل‌های داده
- `routes/` - مسیرهای برنامه
- `views/` - فایل‌های EJS
- `data/` - فایل‌های JSON (دیتابیس)
- `public/` - فایل‌های استاتیک
